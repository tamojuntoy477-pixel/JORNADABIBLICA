# NOX Dragon Arena 3D

Jogo de luta 3D para Android com arena WebGL, controles touch, KI, dash, rajadas de energia, inimigo com IA e ícone próprio.

## APK
O GitHub Actions desta branch gera automaticamente `NOX-Dragon-Arena-3D.apk` e publica o arquivo na seção **Artifacts** da execução.

Fan game original inspirado em batalhas de anime; não inclui sprites ou assets oficiais de Dragon Ball.
