# Painel XITTER — NOX

App Android de demonstração visual.

- Key: `FFTRAPACE`
- Criador: `NOX`
- Tema: galáxia/neon
- Painel flutuante dentro do próprio app
- Abre com 4 dedos ou pelo botão NOX
- Controles de Aimbot/ESP/NoRecoil/etc. são apenas visuais e não acessam nem alteram outros jogos ou aplicativos.

O APK de debug é compilado automaticamente pelo workflow `Build Painel XITTER APK` nesta branch.
